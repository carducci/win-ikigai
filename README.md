# win-ikigai

Signed Windows builds of [ikigai-cli](https://github.com/ikigai-rs/ikigai-cli)'s `ikigai`
command, so a Windows machine with Smart App Control on can install it without building from
source. Maintained by Michael Carducci. This is **not** an official ikigai-rs release: the code
is ikigai-rs's, built from a pinned upstream version, and the signature is ours.

Nothing is released yet. What this repository will do is the OpenSpec change in
[`openspec/changes/`](openspec/changes/); once its first release is out, installing is a
download from the Releases page (and later `winget install`).

## Why it exists

Smart App Control refuses unsigned executables, cargo's build scripts included, so
`cargo install ikigai-cli` fails on a Windows 11 machine that has it on. Windows users get a
signed binary; building from source on Windows stays a contributor's path (WSL2, or a machine
with Smart App Control off).

## How it is worked

It was generated by [ikigai-gonk-starter](https://github.com/ikigai-rs/ikigai-gonk-starter)
(processes `workers`, `hub`, `spec`), so the rules every agent and person here works by are in
[`AGENTS.md`](AGENTS.md):

```text
AGENTS.md                the rules (CLAUDE.md imports it)
openspec/specs/          what this repository does now (nothing yet)
openspec/changes/        the changes in flight
openspec/vectors.json    every scenario of the specs, as steps tests run
artifacts/               one directory per deployable thing
tests/                   the check that the specs and the vectors name the same scenarios
tools/gonk.py            init, seed, file, next, claim, release, report, close, status
```

Its work lives on the `windows` gonk ledger. Every test, as CI runs them:
`python3 scripts/test.py`.
